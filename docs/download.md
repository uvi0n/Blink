# Как скачать Blink и передать первый файл

## Если вам уже прислали ссылку на файлы

Откройте ссылку в браузере телефона или компьютера. Чтобы забрать один файл, нажмите «Скачать» напротив имени. Для всей подборки нажмите «Скачать всё». Для нескольких файлов отметьте галочки и нажмите «Скачать выбранные». ZIP обычно попадает в «Загрузки». На Windows щёлкните его правой кнопкой и выберите «Извлечь всё…». Чтобы получить файлы таким способом, устанавливать Blink не требуется.

Если появился код, сообщите его человеку, который отправил ссылку, и нажмите «Запросить доступ». Дождитесь подтверждения. Если сайт недоступен, попросите отправителя оставить Blink открытым и прислать запасной адрес.

## Если вы хотите сами отправлять файлы с Windows

1. **Скачайте приложение.** Откройте [страницу последнего релиза](https://github.com/uvi0n/Blink/releases/latest). Прокрутите до раздела **Assets**. Если он свёрнут, нажмите на него. Выберите **Blink-Windows-x64.zip**. Два пункта с названием **Source code** содержат исходники для разработчиков.
2. **Найдите скачанный архив.** В Edge или Chrome нажмите **Ctrl + J**. Рядом с Blink-Windows-x64.zip нажмите значок папки. Откроется Проводник.
3. **Распакуйте архив полностью.** Правой кнопкой нажмите на ZIP → **Извлечь всё…** → **Извлечь**. Выберите постоянное место, например папку Blink в «Документах».
4. **Запустите программу.** В распакованной папке откройте **Blink.exe** двойным щелчком. При скрытых расширениях файл называется **Blink**, тип — **Приложение**, значок — синий кинжал. Оставьте остальные файлы рядом: они нужны для QR-кода, шифрования и интернет-соединения. Сборка предназначена для Windows x64 с .NET Framework 4.8 и распространяется без цифровой подписи.
5. **Выберите, что отправить.** Нажмите **Добавить файлы** или перетащите их в окно. Для папки используйте **Добавить папку**. Blink подготовит ZIP, сохранив вложенные папки и пустые каталоги. Для него потребуется свободное место в папке временных файлов. Ссылки файловой системы пропускаются.
6. **Создайте ссылку.** Проверьте список → нажмите **Создать ссылку** → дождитесь надписи **Ссылка проверена**. Нажмите **Копировать** и вставьте адрес в чат сочетанием **Ctrl + V**. Чтобы забрать файлы своим телефоном, нажмите **QR-код** и наведите камеру.
7. **Дождитесь окончания.** Оставьте компьютер включённым и следите за ходом передачи. «Отправлено» означает запись в соединение. Успешное сохранение на устройстве подтверждает браузер получателя. Кнопка **Отозвать** закрывает доступ к обоим адресам. Чтобы отправить ещё одну подборку, сначала отзовите текущую ссылку.

## Ещё пять сценариев

- **Основной адрес недоступен.** В работающей сессии нажмите **Запасной адрес**. После подтверждения нажмите ещё раз и перешлите скопированный второй адрес. Маршруты используют разные сервисы. Готовность второго зависит от сети и установленного клиента Windows OpenSSH. Для докачки используйте прежний URL и функцию возобновления вашего менеджера скачиваний.
- **Собрать фотографии от друзей.** В меню **Запросить** выберите папку, включите **Собрать файлы от нескольких людей**, создайте ссылку. Каждый отправитель открывает её, выбирает файл и нажимает «Отправить». После сохранения можно выбрать следующий. Общего списка чужих загрузок нет. Для одной групповой сессии доступно до 128 заявок на файл.
- **Передать конфиденциальный файл.** Нажмите **Зашифровать файл**, выберите файл и дважды введите стойкую парольную фразу в открывшемся окне age. При вводе символы не отображаются. Опубликуйте подборку только с **Private.age**. Передайте пароль и исходное имя с расширением отдельным доверенным каналом. Получатель скачивает Private.age, запускает Blink → **Расшифровать**, выбирает файл, указывает исходное имя с расширением и вводит пароль. Шифрование и расшифровка происходят на конечных устройствах. Потерянный пароль восстановить невозможно.
- **Отправить из Проводника.** В постоянной распакованной папке один раз запустите **Enable-SendTo.cmd**. Выделите файлы или папки, нажмите правой кнопкой → **Показать дополнительные параметры** (Windows 11) → **Отправить** → **Blink**. Появится подборка, для неё остаётся нажать «Создать ссылку». Чтобы убрать интеграцию, нажмите Win + R, введите shell:sendto и удалите только ярлык Blink.
- **Вернуть прежний вид.** Откройте шестерёнку, выберите одну из шести тем и нажмите «Сохранить». На чистой установке включён «Терминал». При обновлении сохранённый выбор пользователя имеет приоритет.

## Если что-то пошло не так

**После обновления открылась старая версия.** Закройте старую программу через значок в трее → «Выйти». Откройте Blink.exe из новой распакованной папки. Если используете интеграцию Проводника, запустите Enable-SendTo.cmd в новой папке.

**ZIP прервался.** Если браузер предлагает «Продолжить», нажмите это действие, пока сессия и URL действуют. Blink поддерживает запросы диапазонов для ZIP. Пока сервер заново рассчитывает контрольные суммы предыдущих частей, возобновление может занять время.

**Архив скачан, но Windows не показывает приложение.** Проверьте имя ZIP и что он распакован. Не отключайте антивирус и не запускайте копии из незнакомых источников.
